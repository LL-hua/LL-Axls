# LL-Axls

专为道路工程测量打造的纯原生 Android 电子表格应用（60fps 视口虚拟化网格、零依赖 `.xlsx` 读写内核、原生工程公式引擎与专属数字方向小键盘）。

## 核心特性
- **道路测量专属公式引擎 (`fx` 函数向导)**：
  - 平曲线正反算：`=PQX_X(桩号, 偏距, 夹角dms)`、`=PQX_Y(桩号, 偏距, 夹角dms)`、`=PQX_A(桩号)`、`=PQX_K(X, Y)`、`=PQX_B(X, Y)`（自动读取工作簿内「平曲线」表）
  - 竖曲线设计标高：`=SQX_H(桩号)`（自动读取工作簿内「竖曲线」表）
  - 坐标与投影：`=DIST(X1,Y1,X2,Y2)`、`=AZI(X1,Y1,X2,Y2)`、`=FWDX(X,距离,方位角)`、`=FWDY(Y,距离,方位角)`、`=GAUSS_X/Y`、`=UTM_X/Y`
  - 桩号与度分秒：`=NUM2K(米)`、`=DMS2DEG(ddd.mmss)`、`=DEG2DMS(十进制度)`
- **工程数字方向小键盘**：内置 `(`、`)`、`,` 与 `← / → / ↵ 向下` 导航，自动滚屏避让输入法遮挡
- **完整表格排版与安全存储**：支持微信/QQ 外部唤起、`.tmp` 原子保存防 0KB、智能向下填充、合并单元格、行列隐藏与自适应宽高
